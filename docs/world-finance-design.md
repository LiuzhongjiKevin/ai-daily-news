# 国际形势与财经日报：首版设计

## 目标

复用现有 RSS 采集、请求重试、数据校验、邮件发送和防重复发送能力，独立运行国际形势与财经日报。不调用 AI，不生成投资建议，不包含 GitHub 热门项目。

## 版本和运行隔离

- 内容代码及配置位于 `world-finance-daily` 分支，以正式版邮件修复后的提交为基础，不包含 X 采集试验。
- `master` 只增加专用启动工作流，不改 AI 日报的工作流、新闻源或邮件名单。定时工作流需要位于默认分支，这是 GitHub 的限制。
- 启动任务固定检出 `world-finance-daily` 的具体提交运行。代码提交和状态推送仅允许该分支；禁止推送 `master`。
- 独立环境 `world-finance-production`，只使用其中的 `SMTP_USERNAME`、`SMTP_PASSWORD`、`MAIL_TO`。发件邮箱可相同，但不自动抄送发件人，不回退到 AI 日报凭据。
- 独立发送状态目录和任务并发组，不读取 AI 日报的发送记录。每日预留必须持久化成功后才能发送，异常接受结果保留未决状态，禁止盲目重发。
- 正式运行使用独立环境的 `WORLD_FINANCE_STATE_TOKEN` 保存该分支状态，创建方式与旧日报状态令牌相同。沿用现有仓库安全约束：内置凭据只读、检出后不保留凭据，写入令牌仅临时传给固定目的地的推送操作。

## 内容

- 中文栏目名称：国际形势、宏观经济与财经。
- 最近 24 小时最多 12 条，两栏各最多 6 条，不为凑数加入过期新闻；明确标注采集窗口与来源缺失。
- 未接入翻译模型，英文来源保留英文标题和短摘要，不宣称已经自动翻译。
- 优先外交、冲突、贸易与制裁、央行政策、通胀、就业、重大市场及能源事件；降低地方生活资讯、广告及日常企业宣传的优先级。
- 规则评分只表示选稿优先级，不代表事实置信度。机构公告标为官方来源，媒体报道保留媒体名称，单一来源不表述为已获多方确认。
- 以规范化链接和相似标题去重，日期必须可解析；排除未来时间和过期条目，未知日期不编造。
- 邮件包含原文链接、发布时间、短摘要和覆盖情况。所有外部文本转义，不绕过付费墙，不转载全文。

## 时间与发送开关

- 目标北京时间 08:00 前送达，初步安排 06:37 首次运行、07:17 检查补位，成功发送后当日跳过。
- GitHub 排队可能延迟，不能保证 08:00 前完成。
- 专用开关 `WORLD_FINANCE_SCHEDULE_ENABLED` 默认关闭；凭据配置和一次预览验证完成前不启用邮件任务。
- 提供不带邮件凭据的手动预览事件 `world-finance-preview`；发送必须明确触发 `world-finance-send`，同日重复触发会跳过。首版不提供绕过防重的自动补发；未决发送状态需核实实际结果后恢复，不能让代码推送自动发邮件。

## 验收

1. 离线测试覆盖分类、评分、去重、日期边界、HTML 转义、只向新名单发送以及独立状态。
2. GitHub 运行一次无邮件凭据的来源验证与预览，报告每个源实际状态，不把 HTTP 200 等同于采集成功。
3. 下载并检查预览；至少两个独立发布机构有合格内容才允许正常日报发送，全部无数据时失败且不发空白日报。
4. 收件人配置完成并经用户许可后发送一次真实日报，分别确认服务器接受与实际收件，之后再开启定时任务。
5. 核对 AI 日报的配置和工作流没有被修改，旧的 X 测试没有合并。

## 实施前确认

请确认首版英文标题与短摘要保留原文、最多 12 条的内容范围。实际收件邮箱随后由用户填写到独立环境的 `MAIL_TO`，不要把密码或令牌写入文档。
